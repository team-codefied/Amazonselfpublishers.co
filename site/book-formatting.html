Overview

What this service covers

Formatting is the quiet part of book design. When it is done well, nobody notices. When it is done badly, readers see cramped margins, awkward line breaks and inconsistent headings.

We build print interiors with the correct trim size, margins and page numbering, and separately build reflowable ebooks that adapt to any screen.

Who it is for

  • Authors with a Word or Google Docs manuscript
  • Authors whose uploads showed errors
  • Writers needing ebook and paperback files
  • Authors of illustrated or non-fiction titles

FAQ

Book Formatting: frequently asked questions

What is the difference between print and ebook formatting?

Print is fixed: every page is laid out. Ebooks reflow to the reader's device, so they are built differently.

Which trim size should I choose?

It depends on genre and length. We recommend sizes commonly used for your type of book.

Can you format images and tables?

Yes, with attention to resolution and placement. Complex layouts may affect the quote.

Do I need to edit before formatting?

Yes, ideally. Text changes after layout can create extra work.
